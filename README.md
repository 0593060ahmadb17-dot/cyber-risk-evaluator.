# نظام تقييم المخاطر السيبرانية الفردية اعتمادًا على البيانات الرقمية والسلوكية باستخدام الذكاء الاصطناعي

## 📌 نبذة عن المشروع
هذا النظام هو نموذج أولي عملي (Prototype) لمشروع تخرج جامعي، يهدف إلى قياس وتقييم المخاطر السيبرانية على مستوى الأفراد داخل المؤسسات أو الجامعات، عبر دمج المؤشرات الرقمية الفنية (مثل المصادقة الثنائية وتاريخ التسجيلات) مع المؤشرات السلوكية البشرية (مثل معدل النقر على روابط التصيد وقوة كلمات المرور)، واستخدام خوارزميات التعلم الآلي للتنبؤ بمستوى الخطورة.

## 🛠️ التقنيات المستخدمة
- **Python**: لغة البرمجة الأساسية.
- **Streamlit**: لبناء واجهة المستخدم التفاعلية واللوحات الإحصائية.
- **Scikit-Learn**: لبناء وتدريب نموذج `Random Forest Classifier`.
- **SQLite**: لإدارة وتخزين البيانات.
- **Plotly & Seaborn**: لإنشاء الرسوم البيانية التفاعلية وتحليل البيانات.

## 🚀 طريقة التشغيل على حاسوبك الشخصي

1. تأكد من تثبيت لغة Python (الإصدار 3.9 أو أحدث) على جهازك.
2. قم بإنشاء مجلد جديد للمشروع وضع فيه الملفات الثلاثة (`requirements.txt`, `database_setup.py`, `app.py`).
3. افتح موجه الأوامر (Terminal أو CMD) في مجلد المشروع، وثبت المكتبات المطلوبة عبر الأمر التالي:
